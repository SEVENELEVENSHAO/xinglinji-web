# 杏林记 · web build

Browser build of **杏林记**, a Ming-dynasty herbal-clinic game: patients present
symptoms, you compose a formula from the cabinet, and the game reveals the
prescription a famous physician recorded in the casebook.

**Play:** https://sevenelevenshao.github.io/xinglinji-web/

This repository only holds the exported game files (Godot 4.7 web export).
Progress is saved in your browser.
